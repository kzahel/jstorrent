JSTorrent · ChromeOS Linux

Connect to Linux

Linux has its own library, settings and download folders. Android torrents stay in Android.

Choose Connect to check the Linux service.

If Linux does not connect

  1. Open Terminal from the Chromebook Launcher and select penguin if shown. Wait for the Linux command prompt.
  2. Open JSTorrent for ChromeOS Linux from the Launcher, then return here and select Retry.
  3. If you recently updated the extension, update the Linux app too. Current versions use a local connection that avoids Linux hostname-registration failures. Keep your Linux environment and downloaded files.

A failed connection cannot tell us whether Linux is enabled, the package is installed, or device policy permits it. Do not remove the Linux environment or reinstall it to fix a connection error.
