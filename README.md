# JSTorrent

JSTorrent is a fast, efficient BitTorrent client with a modern, easy-to-use
interface. Download and share files on your computer, phone, or Chromebook.

**[Download JSTorrent](https://jstorrent.com/#download)** ·
**[Google Play](https://play.google.com/store/apps/details?id=com.jstorrent.app)** ·
**[Chrome Web Store](https://chromewebstore.google.com/detail/jstorrent/dbokmlpefliilbjldladbimlcfgbolhk)**

## Platforms

| Platform | Status | Get started |
| --- | --- | --- |
| Windows | Available | [Download the desktop app](https://jstorrent.com/#download) |
| macOS | Available | [Download the desktop app](https://jstorrent.com/#download) |
| Linux | Available | [Download the AppImage](https://jstorrent.com/#download) |
| Android | Available | [Install from Google Play](https://play.google.com/store/apps/details?id=com.jstorrent.app) |
| ChromeOS | Available | [Install the Android app](https://play.google.com/store/apps/details?id=com.jstorrent.app), or [use Linux](https://jstorrent.com/#no-play-store) |
| Chrome extension | Available | [Install from the Chrome Web Store](https://chromewebstore.google.com/detail/jstorrent/dbokmlpefliilbjldladbimlcfgbolhk) |
| iOS | In development | — |

The desktop and Android apps work on their own. The optional Chrome extension
connects to the desktop or Android app for browser integration.

## Features

- **Easy to get started.** Open a `.torrent` file or add a magnet link.
- **Download what you want.** Choose individual files and set their priorities.
- **Pick up where you left off.** Pause and resume transfers, with your library
  saved between sessions.
- **Control your bandwidth.** Set download and upload speed limits.
- **Share your downloads.** Keep seeding completed torrents.
- **A modern interface.** Organize your library, follow transfer progress, and
  choose a light or dark appearance.
- **Details when you need them.** Inspect files, peers, trackers, and transfer
  statistics.
